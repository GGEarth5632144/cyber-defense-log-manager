# Log Manager Frontend Dashboard

This directory contains the user interface for the Log Management System. It is built as a **Single Page Application (SPA)** using modern web technologies to provide a lightning-fast, responsive experience for security analysts.

## Tech Stack
- **React 18**: Core UI library.
- **Vite**: Ultra-fast build tool and development server.
- **TypeScript**: Enforces strict typing to prevent runtime errors.
- **Tailwind CSS**: Utility-first CSS framework used for all styling.
- **Recharts**: Composable charting library used for the Dashboard data visualizations.
- **Lucide-React**: SVG icon library.

## Component Architecture
- **`App.tsx`**: The root component. Handles React Router DOM navigation, global Axios defaults, and the primary Layout wrapper.
- **`Dashboard.tsx`**: Fetches aggregate statistics and renders the Timeline, Top IPs, Top Users, and Top Event Types. Includes dropdowns for dynamic time-range and tenant filtering.
- **`LogViewer.tsx`**: A tabular, searchable interface for viewing the raw, normalized logs.
- **`Alerts.tsx`**: Displays high-severity system alerts generated by the backend rule engine.

## Authentication Flow
When a user logs in, the backend returns a JWT token. This token is securely stored in `localStorage`. The application then configures a global Axios interceptor (`axios.defaults.headers.common`) to automatically attach this `Bearer` token to all outbound API requests. Navigation is handled client-side via React Router to prevent full page reloads and maintain the auth state securely in memory.

## Local Development
If you wish to run the frontend outside of Docker for active development:

```bash
# Install dependencies
npm install

# Start the Vite development server (defaults to http://localhost:5173)
npm run dev
```

## Production Build
In production (Appliance or SaaS mode), the frontend is compiled into static HTML/JS/CSS assets via `npm run build`. These static assets are then securely and efficiently served by the **Nginx** Alpine container defined in `Dockerfile`.
